How this map works

The airport directory comes from the publicly maintained OurAirports dataset. Colored markers appear only for airports with successfully retrieved forecast values. Up to 480 airports are sampled per refresh in geographic batches, with airports near the current map view prioritized. Gray markers mean no forecast has been loaded, not good or bad weather. Forecast values are retrieved in batches from Open-Meteo, with dates in the airport's local time zone. Neither service requires an API key. The map is not certified for flight planning.
