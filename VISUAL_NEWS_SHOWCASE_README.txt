VISUAL NEWS SHOWCASE: Three independent browser RSS gateways are tried for each publisher feed. Headlines must be published within 48 hours and contain an image URL. Images are publisher-provided, not AI-generated. This is a best-effort browser-only system, not guaranteed live: third-party gateways may block or rate-limit requests, and some publishers block hotlinked images. For guaranteed availability, a server-side Cloudflare Worker RSS proxy with image handling is required. No OpenAI API is used.
